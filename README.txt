COMO EXECUTAR
-------------
Opção 1:
Abra o arquivo index.html diretamente no navegador.

Opção 2:
No VS Code, use a extensão Live Server.

Opção 3:
Com Python instalado:
    python -m http.server 8000

Depois acesse:
    http://localhost:8000
